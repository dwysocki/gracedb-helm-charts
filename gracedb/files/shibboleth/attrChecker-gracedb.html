Authorization Error

You have successfully authenticated but your session does not contain group membership information. Such information is required for authorization to view content in GraceDB. The best way to proceed depends on whether you are an LVC member or a member of an MOU partner group (such as LV-EM, GW-HEN, etc.).

Advice for LVC Members

  • First, make sure to log into GraceDB with your LIGO.org credentials rather than any other institutional login credentials. This is essential to determining group membership information.
  • Make a fresh attempt to login using a private browsing window (or, alternatively, after clearing your browser cache). This helps sometimes because previously stored session information can interfere with the login process.

Advice for MOU partners

  • To access GraceDB, you will first need to register first via gw-astronomy.org.
  • If you have already registered, make sure that you log in to GraceDB using the same credential that you registered on gw-astronomy.org. This is essential to determining group membership information.
